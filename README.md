# 📚 AI Study Hub
An AI-powered platform that helps students revise faster by turning their notes into **summaries, flashcards, and practice quizzes**.  

## 🚀 Problem
Students often struggle with revising huge notes before exams. Reading everything again is time-consuming and inefficient.

## 💡 Solution
Upload your notes → AI automatically generates:
- **Summaries** → Condensed version of key concepts.
- **Flashcards** → Question-answer style revision cards.
- **Quizzes** → Practice multiple-choice questions for self-testing.

This makes last-minute revision **fast, focused, and effective**.

---

## 🛠️ Tech Stack
- **Frontend:** [Next.js](https://nextjs.org/) (TypeScript, Tailwind CSS)
- **Backend:** Next.js API Routes
- **Database:** MongoDB or PostgreSQL
- **AI Integration:** OpenAI API (can swap with Hugging Face / LangChain)
- **Auth:** NextAuth.js (Google Login)

---

## 📦 Features (MVP)
- Upload notes (text or files like PDF/DOCX).
- AI-generated summaries, flashcards, and quizzes.
- Clean dashboard with tabs for outputs.
- Copy/download results.

### 🎯 Stretch Features
- Save notes & results with authentication.
- Organize by subjects/folders.
- Share study sets with friends.
